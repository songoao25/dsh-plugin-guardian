## 这是什么？

一个 DeepSeek Harness 插件，帮你**安全地卸载其他插件**——不留残留文件、不搞坏启动、全程不用碰命令行。

如果你卸载过 DSH 插件，遇到过留下 `.bak` 备份文件、孤立数据目录、或者卸完之后整个 Harness 启动不了的情况——这个工具就是来解决这些问题的。

## 功能

- **已装插件列表** —— 查看所有已装插件的名称、版本和数据目录
- **残留扫描** —— 查找历次操作留下的 `.bak` 备份文件和孤立数据
- **一键清理** —— 预览后确认删除残留文件
- **卸载前自动快照** —— 卸载任何插件前自动备份配置文件
- **安全卸载** —— 一个按钮完成：快照 → 卸载 → 清数据 → 清残留
- **启动前体检** —— 检查端口 3080 占用、配置完整性、Bundle 状态

## 安装

```bash
# 在你的 DSH 工作区目录下执行
dsh plugin add dsh-plugin-guardian
```

或者手动将此目录复制到你的 DSH 插件文件夹，然后重启 Harness。

## 使用方法

1. 打开 DSH 设置页（侧边栏底部的齿轮图标）
2. 找到 **"插件管家"** 标签页
3. 点击三个按钮中的任意一个：
   - **已装插件** —— 查看和卸载插件
   - **扫描残留** —— 查找和清理残留文件
   - **启动前体检** —— 重启前检查系统健康状态

### 卸载一个插件

1. 点击 **已装插件** 查看已安装的插件列表
2. 点击要卸载插件旁边的 **卸载** 按钮
3. 确认操作——管家会自动：
   - 创建配置文件快照（备份到 `~/.dsh/.plugin-guard-snapshots/`）
   - 执行 `pnpm remove` 卸载插件包
   - 清理该插件的数据目录
   - 清理相关的 `.bak` 残留文件
4. **手动重启 DSH** 使变更生效（如执行 `zsh scripts/restart-deepseek-harness.sh`）

## 常见问题

**问：为什么卸载后需要手动重启？**
答：DSH 是"启动时组装插件"的架构，拆掉一块积木需要重新组装。自动重启功能计划在后续版本实现。

**问：快照存在哪里？**
答：存在 `~/.dsh/.plugin-guard-snapshots/<时间戳>-<插件名>/` 下，只在本地，不上传云端。

**问：安全吗？**
答：所有删除操作都需要二次确认。插件名经过安全验证防止注入攻击。Shell 命令经过标准转义。

## 已知限制

- 快照自动还原功能为实验性（快照已创建，但自动还原界面尚未完成）
- 自动重启功能暂缓——卸载后需手动重启
- 残留扫描仅覆盖顶层目录
